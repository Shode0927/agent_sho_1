熱力学の課題（等温過程と断熱過程の違いについてのレポート）をPDFで出力するには、以下のコマンドを実行してください。

`run.py` を確認したところ、`--pdf` フラグを使うことでPDF形式での出力が可能です。課題のテキストはコマンドライン引数として直接渡せます。

以下のコマンドを実行してください：

```bash
python run.py "等温過程と断熱過程の違い" --pdf
```

このコマンドの意味：
- `"等温過程と断熱過程の違い"` — レポートのテーマ（課題テキスト）
- `--pdf` — PDF形式で出力するフラグ

実行すると、レポートエージェントが課題に基づいてレポートを生成し、PDF形式で保存します。出力ファイルは通常 `output/` ディレクトリに保存されます。

事前に必要なものが揃っているか確認しておくと良いでしょう：
- Pythonの依存パッケージが `pip install -r requirements.txt` でインストール済みであること
- 必要な設定（APIキーなど）が `config.py` に設定済みであること
